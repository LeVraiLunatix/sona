installer

installer. ou ouvrir.

dans le navigateur, rien à télécharger. sur l'écran d'accueil, elle se lance en plein écran comme une app.

sur iphone.

  1. ouvre alyra dans safari.
  2. touche partager, en bas de l'écran.
  3. choisis sur l'écran d'accueil.
  4. lance-la : plein écran, comme une app.
ouvrir dans safari.

sur android.

  1. ouvre alyra dans chrome.
  2. touche le menu ⋮, en haut à droite.
  3. choisis installer l'application.
  4. elle apparaît avec tes apps, sans barre d'adresse.
ouvrir dans chrome.

sur windows.

  1. télécharge l'installateur.
  2. lance-le, puis connecte-toi.
  3. raccourcis clavier, mode jeu et télécommande depuis le téléphone.
télécharger pour windows.

dans le navigateur.

  1. clique sur ouvrir.
  2. connecte-toi avec last.fm.
  3. écoute. rien d'autre à faire.
ouvrir dans le navigateur.

aussi : le bot telegram, et un plugin stream deck pour piloter depuis ton bureau.

questions

en bref.

comment y entrer ?

connecte-toi avec last.fm. un administrateur valide ensuite ton compte : tant que ce n'est pas fait, l'accès reste fermé.

ça marche hors ligne ?

oui, pour les titres que tu as téléchargés. le reste a besoin d'une connexion.

les paroles sont décalées ?

règle le décalage : plus ou moins, par pas de 0,1 s. alyra s'en souvient pour ce titre.

sur quels appareils ?

navigateur, iphone, android, windows. plus le bot telegram et un plugin stream deck.
